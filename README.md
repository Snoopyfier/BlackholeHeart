# Slimed Out
information about your project, what is it, what does it do, etc.
Slimed Out is a fun little puzzle platformer game made fully in *Gamemaker*. It's quite a simple project but is only my second shipped game!
The entire game is **GML**, so nothing extra special happening with it.

The project was mainly made over 3 days, but started a couple weeks before the main block of developement. 

The itch.io link for the game is laid out below:
https://snoopydrr.itch.io/slimed-out


AI was used during this project however only for helping with bugs that I couldn't find, even though it wasn't very helpful😭, and with teaching me how to code some things I didn't know how to, like the transitions in the game, as this is my second time coding in GML. **There is no copy and pasted code from artificial intelligence.**
